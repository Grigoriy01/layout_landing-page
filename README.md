# Landing Page

My Bike — One-Page Landing

Overview
“My Bike” is a responsive one-page landing designed and built to showcase modern front-end development practices. The project focuses on clean structure, maintainable SCSS architecture, and performance-optimized build using Parcel.
The layout recreates a selected design (MYBIKE) and includes key sections such as a product presentation, model comparison, and a contact form.

Key Technologies & Tools

HTML5, SCSS — semantic structure and modular styling.

Parcel — fast local development and production builds.

Mate-scripts toolkit — scripts for running, linting, testing, and deployment.

Stylelint, Prettier, ESLint, Cypress, Jest — ensuring code quality and consistency.

Setup Instructions

npm install      # install dependencies
npm run dev      # start development server
npm run lint     # check styles and formatting
npm run build    # build the project
npm run deploy   # deploy to GitHub Pages
